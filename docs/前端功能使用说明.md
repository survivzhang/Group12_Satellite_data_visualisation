# 卫星数据可视化系统 - 前端功能使用说明

## 📋 概述

本系统是一个基于Web的卫星数据可视化平台，支持多种卫星数据源的实时查看和分析。用户可以通过直观的界面浏览不同卫星的海表温度、叶绿素浓度等科学数据。

## 🗺️ 主要功能

### 1. **多地图实例管理**
- **功能**: 最多同时显示4个地图窗口
- **用途**: 对比不同卫星数据或参数
- **操作**: 点击"+ Add Map"按钮添加新地图

### 2. **参数选择器 (Data Parameters)**
- **功能**: 选择要显示的卫星数据参数
- **可用参数**:
  - 🌡️ **海表温度 (SST)**: Himawari、Sentinel-3A、Sentinel-3B
  - 🌿 **叶绿素浓度 (CHL)**: Sentinel-3A、Sentinel-3B
  - 👁️ **反射率 (B02)**: Sentinel-2A、Sentinel-2B
  - 🌊 **海表高度异常 (SSHA)**: SWOT
- **操作**: 展开参数面板，点击参数名称添加到地图

### 3. **时间轴控制 (Temporal Analysis)**
- **功能**: 选择查看的时间点和时间范围
- **时间分辨率选项**:
  - 📅 **Months**: 月级别
  - 📅 **Weeks**: 周级别  
  - 📅 **Days**: 日级别
  - ⏰ **Hours**: 小时级别
- **播放控制**:
  - ▶️ **播放/暂停**: 自动时间轴播放
  - ⏮️ **快退**: 跳到开始
  - ⏯️ **单步**: 逐步前进/后退
  - ⏭️ **快进**: 跳到结束
- **操作**: 拖动时间轴滑块或使用播放控件

### 4. **地图视图模式**

每个地图支持三种显示模式：

#### 📸 **Static (静态图模式)**
- **用途**: 查看预生成的高质量卫星图像
- **特点**: 
  - 加载速度快
  - 图像质量高
  - 严格的时间匹配
- **适用场景**: 精确的时间点数据查看

#### 🎯 **Interactive (交互地图模式)**  
- **用途**: 点式数据交互查看
- **特点**:
  - 可点击查看具体数值
  - 基于Leaflet地图
  - 采样优化性能
- **适用场景**: 探索性数据分析

#### 🎨 **Canvas Heatmap (画布热力图模式)**
- **用途**: 高分辨率热力图显示
- **特点**:
  - 完整数据点显示
  - 实时渲染
  - 与地图完全集成
- **适用场景**: 详细的空间分析

### 5. **数据范围过滤 (Range Control)**
- **功能**: 设置数据值的显示范围
- **用途**: 突出特定数值范围的数据
- **操作**: 
  1. 点击地图上的"Range"按钮
  2. 输入最小值和最大值
  3. 点击"Apply"应用过滤
  4. 点击"Reset"重置为原始范围

### 6. **图像信息查看**
- **功能**: 查看当前显示图像的详细信息
- **信息内容**:
  - 📁 文件名
  - 📊 数据统计 (最小值、最大值、平均值)
  - 🌐 URL路径
  - 💾 本地路径
- **操作**: 点击地图上的"Image Info"按钮

### 7. **全屏模式**
- **功能**: 将单个地图放大到全屏显示
- **用途**: 详细查看数据细节
- **操作**: 点击地图右上角的全屏按钮

### 8. **数据更新**
- **功能**: 手动刷新数据源
- **用途**: 获取最新的卫星数据
- **操作**: 点击主界面的刷新按钮
- **状态显示**: 显示最后更新时间和缺失文件数量

## 🔄 工作流程示例

### 基础使用流程
1. **选择参数**: 展开"Data Parameters"，选择感兴趣的卫星数据
2. **添加地图**: 点击参数添加到地图窗口
3. **设置时间**: 使用时间轴选择要查看的时间点
4. **选择视图**: 根据需求切换Static/Interactive/Canvas模式
5. **数据分析**: 查看数据值、设置范围过滤、获取详细信息

### 对比分析流程
1. **添加多个地图**: 最多添加4个地图实例
2. **选择不同参数**: 每个地图选择不同的卫星或参数
3. **同步时间**: 所有地图共享相同的时间轴
4. **对比观察**: 同时观察不同数据源的变化趋势

## ⚙️ 高级功能

### 🎯 精确数据查询
- **Interactive模式**: 点击地图任意位置查看精确数值
- **数据提示**: 鼠标悬停显示坐标和数值信息
- **统计信息**: 自动计算并显示数据的最小值、最大值、平均值

### 🖼️ 图像导出和分享
- **URL复制**: 通过Image Info获取图像URL
- **路径信息**: 查看本地文件路径
- **快照功能**: 浏览器右键保存当前视图

### ⏱️ 时间序列分析
- **播放模式**: 自动播放时间序列，观察数据变化
- **精确定位**: 通过时间轴精确选择特定时间点
- **多分辨率**: 支持从小时到月的不同时间粒度

## 🔧 技术特点

### 性能优化
- **数据采样**: Interactive模式自动采样大数据集
- **智能缓存**: 自动缓存已加载的图像
- **按需加载**: 只加载当前显示的时间点数据

### 响应式设计
- **自适应布局**: 支持不同屏幕尺寸
- **全屏支持**: 每个地图都可独立全屏
- **移动友好**: 支持触摸操作

### 数据一致性
- **统一时间轴**: 所有地图共享相同的时间控制
- **同步更新**: 时间变化时所有地图同时更新
- **状态保持**: 刷新页面后保持用户设置

## 🚨 注意事项

### 数据可用性
- 不同卫星的数据可用时间可能不同
- 某些时间点可能没有数据，系统会显示"No data available"
- Canvas模式可能显示最接近的可用数据

### 性能建议
- 同时显示4个地图可能影响性能
- 大数据集建议使用Static模式查看
- 网络较慢时建议减少同时显示的地图数量

### 浏览器兼容性
- 推荐使用Chrome、Firefox、Safari等现代浏览器
- 需要启用JavaScript
- 建议使用较新版本的浏览器以获得最佳体验
