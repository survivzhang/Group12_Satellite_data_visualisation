# 卫星数据可视化系统 - 时间轴处理逻辑文档

## 📋 概述

本文档详细说明了卫星数据可视化系统中静态图像的时间轴处理逻辑，包括两个主要卫星数据源（Himawari和Sentinel-3）的不同时间处理策略。

## 🛰️ 支持的卫星数据源

| 卫星 | 参数代码 | 数据类型 | 时间精度 | 文件格式 |
|------|----------|----------|----------|----------|
| Himawari-9 | `ssth` | 海表温度 | 1小时间隔 | `YYYYMMDDHHMMSS.png` |
| Sentinel-3A | `sst-s3a` | 海表温度 | 不规则间隔 | `YYYYMMDD_HHMMSS.png` |
| Sentinel-3A | `chl-s3a` | 叶绿素浓度 | 不规则间隔 | `YYYYMMDD_HHMMSS.png` |

## 1️⃣ Himawari-9 时间处理逻辑

### 数据特征
- **采集间隔**: 每小时整点（如 00:00, 01:00, 02:00）
- **数据延迟**: 4小时处理延迟
- **时间精度**: 小时级别（分钟和秒始终为00）

### 前端时间戳生成
```typescript
// 用户选择时间: 2025-03-31 15:26:24
const utcDate = new Date(timeRange.start.getTime());
```

### 时间提取函数
```typescript
const extractTimeFromSentinel3Filename = (filename: string): Date | null => {
  // 文件格式: YYYYMMDD_HHMMSS.png
  const timeMatch = filename.match(/(\d{8})_(\d{6})\.png$/);
  if (timeMatch) {
    const dateStr = timeMatch[1]; // YYYYMMDD
    const timeStr = timeMatch[2]; // HHMMSS
    
    const year = dateStr.substring(0, 4);
    const month = dateStr.substring(4, 6);
    const day = dateStr.substring(6, 8);
    const hour = timeStr.substring(0, 2);
    const minute = timeStr.substring(2, 4);
    const second = timeStr.substring(4, 6);
    
    return new Date(`${year}-${month}-${day}T${hour}:${minute}:${second}Z`);
  }
  return null;
};
```

- **存储路径**: `/static/sentinel3a/sst/png/20250331_152630.png`

## 🎯 设计原理

### Himawari 设计考虑
1. **数据特性**: Himawari数据本身就是整点采集
2. **简化处理**: 避免复杂的时间插值
3. **用户期望**: 海洋数据的小时级精度已足够
4. **系统性能**: 精确匹配避免搜索算法开销

### Sentinel-3 设计考虑
1. **数据丰富性**: Sentinel-3提供更高时间分辨率
2. **最佳体验**: 显示最接近用户选择时间的数据
3. **历史原则**: 避免显示"未来"数据
4. **数据连续性**: 支持时间序列的平滑播放

## 🔮 系统优势

1. **智能适配**: 根据不同卫星特性采用最优策略
2. **用户友好**: 自动处理复杂的时间匹配逻辑
3. **数据完整性**: 确保显示的数据与时间轴一致
4. **性能优化**: 高效的文件查找算法
5. **扩展性**: 易于添加新的卫星数据源

## ⚠️ 重要发现：静态图与Canvas的时间处理差异

### 📊 关键问题描述

在相同时间点下，**静态图显示"无数据"，而Canvas能正常显示数据**。这种现象的根本原因是两套系统采用了不同的时间匹配原则。

### 🔍 现象示例分析

#### 实际观察到的场景
```
用户选择时间: 2025-03-01 09:12 AM
├── 静态图结果: "No satellite data for 20250301_010000"
└── Canvas结果: 正常显示叶绿素浓度热力图
```

#### NC文件内容假设
```
NC文件: 20250923_211031.nc 包含多个时间切片:
├── 2025-03-02 14:30:00 (有有效数据)
├── 2025-03-03 08:15:00 (有有效数据)  
├── 2025-03-04 16:45:00 (有有效数据)
└── ... 更多时间点
```

### 🎯 根本差异：时间匹配策略

| 特性 | 静态图策略 | Canvas策略 |
|------|----------|-----------|
| **匹配原则** | 严格历史原则 | 最近时间原则 + 智能回退 |
| **时间限制** | 只选择 ≤ 用户选择时间的数据 | 选择最接近用户时间的数据（无论前后） |
| **无匹配时** | 显示"无数据可用" | 自动回退到第一个有效时间点 |
| **数据来源** | 预生成PNG文件 | NC文件中的任意时间切片 |

### 📋 详细处理逻辑对比

#### 1️⃣ 静态图：严格历史匹配
```typescript
// 前端文件查找逻辑

  let bestTimeDiff = Infinity;

    // 🔑 关键限制：只考虑历史文件
    if (fileTime && fileTime.getTime() <= selectedTime.getTime()) {
      const timeDiff = selectedTime.getTime() - fileTime.getTime();
      if (timeDiff < bestTimeDiff) {

        bestFile = file;

  }

```

**结果**: 用户选择2025-03-01，但所有PNG都是2025-03-02之后的，所以返回null。

#### 2️⃣ Canvas：智能时间匹配 + 回退机制
```python
# 后端时间切片提取逻辑
def get_sentinel3_data(data_var, target_time=None, time_coords=None):
    if target_time and time_coords is not None:
        try:
            target_dt = datetime.fromisoformat(target_time)
            
            # 🔑 关键差异：找最接近的时间（无论前后）
            time_diffs = [abs((t - target_dt).total_seconds()) for t in time_coords]
            closest_time_idx = np.argmin(time_diffs)
            data = data_array[closest_time_idx]
            
            # 检查数据有效性
            valid_data = data[~np.isnan(data)]
            if len(valid_data) == 0:
                # 🛡️ 智能回退：使用第一个有效时间点
                return find_first_valid_timepoint(data_var)
            else:
                return data
                
        except Exception:
            # 🛡️ 异常回退：使用第一个有效时间点
            return find_first_valid_timepoint(data_var)
    else:
        # 🛡️ 默认回退：使用第一个有效时间点
        return find_first_valid_timepoint(data_var)

def find_first_valid_timepoint(data_var):
    """确保总能返回有效数据"""
    for i in range(data_var.shape[0]):
        time_data = data_var.values[i]
        valid_data = time_data[~np.isnan(time_data)]
        if len(valid_data) > 0:
            return time_data  # 返回第一个有数据的时间切片
    
    return data_var.values[0]  # 兜底返回
```

**结果**: 用户选择2025-03-01，系统找到最接近的2025-03-02数据并显示。

### 💡 设计哲学对比

#### 🎯 静态图设计原则
- **时间准确性优先**: 确保显示数据严格对应用户选择时间
- **科学严谨性**: 遵循"不显示未发生事件"的科学原则
- **精确匹配**: 一对一的时间-图像映射关系
- **用户预期**: 符合传统数据分析工具的行为

#### 🎨 Canvas设计原则  
- **数据可用性优先**: 优先确保用户能看到相关数据
- **用户体验**: 避免"无数据"的空白界面
- **智能匹配**: 从可用数据中选择最相关的内容
- **容错性**: 多重回退机制确保系统稳定性

### 🚨 潜在问题与风险

#### 1. **时间误导性**
- **问题**: Canvas可能显示"未来"数据，但用户界面显示的是历史时间
- **风险**: 用户可能误认为该时间点确实有数据
- **影响**: 科学分析的准确性受到影响

#### 2. **数据一致性**
- **问题**: 同一时间点，不同视图显示不同结果
- **风险**: 用户困惑，系统可信度下降
- **影响**: 用户体验和系统专业性

#### 3. **时间溯源困难**
- **问题**: Canvas显示的数据难以追溯到具体时间点
- **风险**: 无法进行精确的时间序列分析
- **影响**: 科研和分析价值降低
